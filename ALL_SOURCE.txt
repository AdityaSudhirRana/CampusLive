# CampusLive handoff

Paste this file plus ALL_SOURCE.txt into a new session to continue.

## Product idea (from the owner)
One platform where teachers, HODs and the principal create, operate and monitor lectures. The core
is the LIVE lecture: a teacher makes a lecture live, and the principal can see it is officially being
held now. Hierarchy: Root Admin > College > Principal > HOD > Teacher > Class/Lecture > Live session > Logs.
Owner prefers: multi-file projects, a design that does not look generic, full summary plus source when
a session nears its limit.

## Stack
Python 3, Flask, SQLite (file campuslive.db), Server-Sent Events for live updates, plain JS frontend
(no build step, classic scripts sharing globals). Start with `python run.py --demo`.

## Done
- v3 (UI pass): landing page before sign-in (hash routes #signin, #signup), pop-up dialogs for every create/edit/confirm form (MODALS registry in views.js), three-dot row menus, page headers with primary action buttons, navy/blue professional palette, editable profile (name, email, phone via POST /api/me/profile), students see Present/Absent only (attendance counts and verification are stripped server-side for students).
- Roles and permissions: root, admin (principal), hod, teacher, student. Root creates colleges (COL001...).
  Principal creates departments + HODs. HOD creates teachers and classes. Students self-register with
  the college code and class.
- Lecture lifecycle: SCHEDULED > LIVE > COMPLETED, plus CANCELLED and MISSED ("not held").
  Go live window: 10 min before start until end. One live lecture per teacher and per room.
  Forgotten lectures auto-end 15 min after scheduled end (sweeper). All steps are logged.
- Official verification: starting a lecture generates a 4-digit class code, visible only to the teacher.
  Students enter it to mark themselves present. 2+ check-ins shows "Verified by students".
- Live board for principal/HOD (grouped by department, elapsed timer, verification, late lectures),
  student board with check-in, lecture detail modal with timeline and attendee names.
- Weekly timetable: a slot generates lectures for up to 12 weeks, skipping room/teacher clashes.
  Clash checking also applies to single lectures.
- HOD: substitute teacher on an unstarted lecture, room change. Teacher: room change.
- Account management: admin/HOD deactivate/reactivate and reset passwords; everyone can change their own.
- Reports per teacher (held, not held, cancelled, held rate, average start delay, average attendance)
  for 7/30/90 days, with CSV download.
- Real-time: SSE per college (`/api/stream`); dashboards re-fetch on each ping, plus 30 s fallback.
- Tests: tests/test_flow.py covers the whole flow. Demo data: campuslive/seed.py.

## Not done (suggested order)
1. Edit/delete for classes, lectures, departments; student management (list, remove, move class).
2. Announcements from principal/HOD to a department or college, shown on boards.
3. Principal drill-down College > Department > Class > Lecture > Teacher pages; room occupancy view.
4. Rate-limit check-in attempts (4-digit code can be guessed); optional time-limited code rotation.
5. Notifications when a lecture goes live (web push / email); reconnect catch-up indicator.
6. Daily/weekly analytics charts; log retention and filters; Root admin per-college usage stats.
7. Production: gunicorn (single worker for SSE or Redis pub/sub), PostgreSQL, HTTPS, CSRF, real SECRET_KEY.

===== README.md =====
# CampusLive

Real-time academic activity monitoring for colleges. Flask + SQLite, live updates over Server-Sent Events.

## Run
    pip install -r requirements.txt
    python run.py --demo        # --demo loads sample data the first time

The terminal prints the address (normally http://127.0.0.1:5000) and opens it in your browser.
If port 5000 is busy, the next free port is used automatically (`PORT=8000 python run.py` to choose).
To open it from other devices on your Wi-Fi: `HOST=0.0.0.0 python run.py`.

## Logins
| Role | Username | Password |
|---|---|---|
| Root admin | root | root123 |
| Demo Principal | principal | demo123 |
| Demo HOD | hod_cs, hod_com, hod_sci | demo123 |
| Demo teacher | teacher_cs1, teacher_cs2, ... | demo123 |
| Demo student | student, student2 | demo123 |

Without `--demo`, start as root, create a college, and build the hierarchy from there.
Change `ROOT_PASSWORD` and `SECRET_KEY` (environment variables) before real use.

Demo class code for the live lecture in Computer Science: 4821 (teacher_cs1 sees it on their lecture).
Tests: `python tests/test_flow.py`. Handoff for continuing in another session: `HANDOFF.md` (all source in `ALL_SOURCE.txt`).

## Layout
    run.py                     starts the server (port fallback, browser open)
    campuslive/
      __init__.py              app factory
      config.py  db.py         settings, SQLite schema and queries
      helpers.py               time, lecture phase, permissions, validation
      realtime.py              Server-Sent Events
      sweeper.py               auto-ends forgotten lectures
      seed.py                  demo data
      routes/                  auth, root, org (depts/HODs/teachers), teaching, monitor
      templates/index.html
      static/css/app.css
      static/js/               util, render, board, views, landing, app

## Lecture rules (edit in config.py)
A teacher can go live from 10 minutes before the start until the end time. A lecture left live is
ended 15 minutes after its scheduled end. A lecture never started is marked "Not held". One live
lecture per teacher and per room. Every step is written to the activity log.

import os, socket, sys, threading, webbrowser

try:
    import flask  # noqa: F401
except ImportError:
    sys.exit("Flask is not installed. Run:  pip install -r requirements.txt")

from campuslive import create_app, config
from campuslive.sweeper import start


def is_free(host, port):
    with socket.socket() as probe:                       # something already listening?
        probe.settimeout(0.3)
        if probe.connect_ex(("127.0.0.1", port)) == 0:
            return False
    with socket.socket() as s:
        try:
            s.bind((host, port)); return True
        except OSError:
            return False


def pick_port(host, wanted):
    for port in range(wanted, wanted + 20):
        if is_free(host, port):
            return port
    sys.exit(f"No free port found from {wanted} to {wanted + 19}. Set PORT to another number.")


if __name__ == "__main__":
    app = create_app()
    if "--demo" in sys.argv:
        from campuslive.seed import seed
        print("Demo data loaded (logins in README)." if seed() else "Demo data skipped: the database already has a college.")
    host = os.environ.get("HOST", "127.0.0.1")
    port = pick_port(host, int(os.environ.get("PORT", 5000)))
    url = f"http://{'127.0.0.1' if host in ('0.0.0.0', '127.0.0.1') else host}:{port}"
    print(f"\n  CampusLive is running at {url}\n  Root login: {config.ROOT_USER} / {config.ROOT_PASSWORD}\n  Stop with Ctrl+C\n")
    start()
    if not os.environ.get("NO_BROWSER"):
        threading.Timer(1.2, webbrowser.open, [url]).start()
    app.run(host=host, port=port, threaded=True, use_reloader=False)

"""SQLite access and schema."""
import sqlite3
from werkzeug.security import generate_password_hash as gph
from .config import DB, ROOT_USER, ROOT_PASSWORD

SCHEMA = """
CREATE TABLE IF NOT EXISTS colleges(id INTEGER PRIMARY KEY, code TEXT UNIQUE, name TEXT, created_at TEXT);
CREATE TABLE IF NOT EXISTS depts(id INTEGER PRIMARY KEY, college_id INT, name TEXT, UNIQUE(college_id,name));
CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY, role TEXT, username TEXT UNIQUE, name TEXT, pw TEXT,
  college_id INT, dept_id INT, class_id INT);
CREATE TABLE IF NOT EXISTS classes(id INTEGER PRIMARY KEY, college_id INT, dept_id INT, name TEXT, UNIQUE(dept_id,name));
CREATE TABLE IF NOT EXISTS lectures(id INTEGER PRIMARY KEY, college_id INT, dept_id INT, class_id INT, teacher_id INT,
  subject TEXT, room TEXT, date TEXT, start_time TEXT, end_time TEXT, status TEXT DEFAULT 'SCHEDULED',
  started_at TEXT, ended_at TEXT);
CREATE TABLE IF NOT EXISTS logs(id INTEGER PRIMARY KEY, ts TEXT, college_id INT, dept_id INT, actor_id INT,
  event TEXT, lecture_id INT, detail TEXT);
"""

def conn():
    c = sqlite3.connect(DB, timeout=10); c.row_factory = sqlite3.Row; return c

def q(sql, a=(), one=False):
    c = conn()
    try:
        r = c.execute(sql, a).fetchall(); c.commit()
        r = [dict(x) for x in r]
        return (r[0] if r else None) if one else r
    finally: c.close()

def ex(sql, a=()):
    c = conn()
    try:
        cur = c.execute(sql, a); c.commit(); return cur.lastrowid
    finally: c.close()

EXTRA = """
CREATE TABLE IF NOT EXISTS attendance(lecture_id INT, student_id INT, ts TEXT, PRIMARY KEY(lecture_id, student_id));
CREATE TABLE IF NOT EXISTS timetable(id INTEGER PRIMARY KEY, college_id INT, dept_id INT, class_id INT, teacher_id INT,
  subject TEXT, room TEXT, weekday INT, start_time TEXT, end_time TEXT);
"""

def migrate(c):
    """Adds newer tables/columns so databases from earlier versions keep working."""
    c.executescript(EXTRA)
    def add(table, col, ddl):
        if col not in [r[1] for r in c.execute(f"PRAGMA table_info({table})")]:
            c.execute(f"ALTER TABLE {table} ADD COLUMN {col} {ddl}")
    add("users", "active", "INT DEFAULT 1")
    add("users", "email", "TEXT")
    add("users", "phone", "TEXT")
    add("lectures", "code", "TEXT")
    add("lectures", "orig_teacher_id", "INT")
    add("lectures", "timetable_id", "INT")


def init_db():
    c = conn(); c.execute("PRAGMA journal_mode=WAL"); c.executescript(SCHEMA); migrate(c); c.commit(); c.close()
    if not q("SELECT 1 FROM users WHERE role='root'"):
        ex("INSERT INTO users(role,username,name,pw) VALUES('root',?,?,?)",
           (ROOT_USER, "Root Admin", gph(ROOT_PASSWORD)))


===== campuslive/helpers.py =====
"""Shared helpers: time, lecture phase, auth guards, validation, scoping."""
import datetime as dt
from functools import wraps
from flask import request, session, jsonify
from werkzeug.security import generate_password_hash as gph
from .db import q, ex
from .config import EARLY, GRACE, VERIFY_MIN

# ---------- helpers ----------
def now(): return dt.datetime.now()
def mins(s): h, m = map(int, s.split(":")); return h * 60 + m
def log(l_or_ids, actor, event, lid=None, detail=""):
    cid, did = l_or_ids
    ex("INSERT INTO logs(ts,college_id,dept_id,actor_id,event,lecture_id,detail) VALUES(?,?,?,?,?,?,?)",
       (now().isoformat(timespec="seconds"), cid, did, actor, event, lid, detail))

def phase(l):
    if l["status"] != "SCHEDULED": return l["status"].lower()
    n = now(); today = n.strftime("%Y-%m-%d"); nm = n.hour * 60 + n.minute
    if l["date"] > today: return "scheduled"
    if l["date"] < today or nm > mins(l["end_time"]): return "missed"
    s = mins(l["start_time"])
    if nm >= s + EARLY: return "late"
    if nm >= s - EARLY: return "available"
    return "scheduled"

def cur():
    uid = session.get("uid")
    u = q("SELECT * FROM users WHERE id=?", (uid,), one=True) if uid else None
    return u if u and u["active"] else None

def need(*roles):
    def deco(f):
        @wraps(f)
        def w(*a, **k):
            u = cur()
            if not u: return jsonify(error="Not signed in"), 401
            if roles and u["role"] not in roles: return jsonify(error="You don't have access to this"), 403
            return f(u, *a, **k)
        return w
    return deco

def body(*req):
    d = request.get_json(silent=True) or {}
    d = {k: (v.strip() if isinstance(v, str) else v) for k, v in d.items()}
    miss = [r for r in req if d.get(r) in (None, "")]
    if miss: raise ValueError("Please fill in: " + ", ".join(miss))
    return d


def add_user(role, d, cid, did=None, class_id=None, name_key="name"):
    if len(d["password"]) < 6: raise ValueError("Password must be at least 6 characters")
    if q("SELECT 1 FROM users WHERE username=?", (d["username"],), one=True): raise ValueError("That username is taken")
    return ex("INSERT INTO users(role,username,name,pw,college_id,dept_id,class_id) VALUES(?,?,?,?,?,?,?)",
              (role, d["username"], d[name_key], gph(d["password"]), cid, did, class_id))

LSQL = """SELECT l.*, (SELECT COUNT(*) FROM attendance a WHERE a.lecture_id=l.id) present, (SELECT COUNT(*) FROM users s WHERE s.class_id=l.class_id AND s.role='student') enrolled, (SELECT name FROM users o WHERE o.id=l.orig_teacher_id) covering_for, t.name teacher, c.name class_name, d.name dept FROM lectures l
 JOIN users t ON t.id=l.teacher_id JOIN classes c ON c.id=l.class_id JOIN depts d ON d.id=l.dept_id"""
def scope(u):
    return {"admin": ("l.college_id=?", u["college_id"]), "hod": ("l.dept_id=?", u["dept_id"]),
            "teacher": ("l.teacher_id=?", u["id"]), "student": ("l.class_id=?", u["class_id"])}[u["role"]]
def lectures(u, where="1", args=(), tail=""):
    w, a = scope(u)
    rows = q(f"{LSQL} WHERE {w} AND {where} {tail}", (a,) + tuple(args))
    checked = set()
    if u["role"] == "student":
        checked = {x["lecture_id"] for x in q("SELECT lecture_id FROM attendance WHERE student_id=?", (u["id"],))}
    for r in rows:
        r["phase"] = phase(r)
        r["verified"] = r["present"] >= VERIFY_MIN
        r["checked"] = r["id"] in checked
        if u["role"] != "teacher":
            r.pop("code", None)          # the class code is only ever shown to the teacher
        if u["role"] == "student":
            for k in ("present", "enrolled", "verified"): r.pop(k, None)   # attendance numbers are for staff only
    return rows



def conflict(cid, teacher_id, room, date, start, end):
    """Returns a message if the teacher or room is already booked in that window, else None."""
    for r in q("SELECT teacher_id,room,subject,start_time,end_time FROM lectures WHERE college_id=? AND date=? "
               "AND status IN ('SCHEDULED','LIVE') AND start_time<? AND end_time>?", (cid, date, end, start)):
        if r["teacher_id"] == teacher_id:
            return f"That teacher already has {r['subject']} from {r['start_time']} to {r['end_time']} on {date}"
        if r["room"] == room:
            return f"Room {room} is already booked for {r['subject']} from {r['start_time']} to {r['end_time']} on {date}"
    return None

===== campuslive/realtime.py =====
"""Server-Sent Events: pushes an update ping to dashboards of a college."""
import queue, threading
from flask import Blueprint, Response, jsonify
from .helpers import cur

bp = Blueprint("realtime", __name__)

# ---------- real-time (Server-Sent Events) ----------
subs, sub_lock = {}, threading.Lock()
def publish(college_id):
    with sub_lock:
        for key in (college_id, 0):
            for qu in subs.get(key, ()): qu.put(1)

@bp.get("/api/stream")
def stream():
    u = cur()
    if not u: return jsonify(error="Not signed in"), 401
    key = u["college_id"] or 0; qu = queue.Queue()
    with sub_lock: subs.setdefault(key, set()).add(qu)
    def gen():
        try:
            yield "retry: 2000\n\n"
            while True:
                try: qu.get(timeout=20); yield "data: update\n\n"
                except queue.Empty: yield ": ping\n\n"
        finally:
            with sub_lock: subs[key].discard(qu)
    return Response(gen(), mimetype="text/event-stream", headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"})

===== campuslive/sweeper.py =====
"""Background job: auto-ends forgotten lectures, marks never-started ones as not held."""
import time, threading
from .db import q, ex
from .config import GRACE
from .helpers import now, mins, log
from .realtime import publish

# ---------- sweeper: auto-end forgotten lectures, mark never-held ones ----------
def sweep():
    while True:
        try:
            n = now(); today = n.strftime("%Y-%m-%d"); nm = n.hour * 60 + n.minute
            for l in q("SELECT * FROM lectures WHERE status IN ('LIVE','SCHEDULED')"):
                ids = (l["college_id"], l["dept_id"])
                over = l["date"] < today or (l["date"] == today and nm > mins(l["end_time"]) + (GRACE if l["status"] == "LIVE" else 0))
                if l["status"] == "LIVE" and over:
                    ex("UPDATE lectures SET status='COMPLETED', ended_at=? WHERE id=?", (l["date"] + "T" + l["end_time"] + ":00", l["id"]))
                    log(ids, None, "LECTURE_AUTO_ENDED", l["id"], f"{l['subject']}: teacher did not end it"); publish(l["college_id"])
                elif l["status"] == "SCHEDULED" and (l["date"] < today or (l["date"] == today and nm > mins(l["end_time"]))):
                    ex("UPDATE lectures SET status='MISSED' WHERE id=?", (l["id"],))
                    log(ids, None, "LECTURE_NOT_HELD", l["id"], f"{l['subject']} was never made live"); publish(l["college_id"])
        except Exception as e: print("sweep error", e)
        time.sleep(30)


def start():
    threading.Thread(target=sweep, daemon=True).start()

bp = Blueprint("auth", __name__)

# ---------- auth ----------
@bp.post("/api/login")
def login():
    d = body("username", "password")
    u = q("SELECT * FROM users WHERE username=?", (d["username"],), one=True)
    if not u or not cph(u["pw"], d["password"]): raise ValueError("Wrong username or password")
    if not u["active"]: raise ValueError("This account has been deactivated. Contact your administrator")
    session["uid"] = u["id"]; return me_json(u)

@bp.post("/api/logout")
def logout(): session.clear(); return jsonify(ok=1)

def me_json(u):
    if not u: return jsonify(user=None)
    col = q("SELECT code,name FROM colleges WHERE id=?", (u["college_id"],), one=True) if u["college_id"] else None
    dep = q("SELECT name FROM depts WHERE id=?", (u["dept_id"],), one=True) if u["dept_id"] else None
    return jsonify(user=dict(id=u["id"], role=u["role"], name=u["name"], username=u["username"], email=u["email"], phone=u["phone"], college=col, dept=dep and dep["name"]))

@bp.get("/api/me")
def me(): return me_json(cur())

@bp.get("/api/public/classes")
def public_classes():

from flask import Blueprint, request, session, jsonify, Response

import csv, io

SQL = """SELECT t.name teacher, d.name dept, COUNT(*) total,
  SUM(l.status IN ('COMPLETED','LIVE')) held, SUM(l.status='MISSED') missed, SUM(l.status='CANCELLED') cancelled,
  AVG(CASE WHEN l.started_at IS NOT NULL THEN (strftime('%s',l.started_at)-strftime('%s',l.date||'T'||l.start_time||':00'))/60.0 END) delay,
  AVG(CASE WHEN l.status IN ('COMPLETED','LIVE') THEN (SELECT COUNT(*) FROM attendance a WHERE a.lecture_id=l.id)*100.0/
      NULLIF((SELECT COUNT(*) FROM users s WHERE s.class_id=l.class_id AND s.role='student'),0) END) attendance
  FROM lectures l JOIN users t ON t.id=l.teacher_id JOIN depts d ON d.id=l.dept_id
  WHERE {w} AND l.date>=? AND l.status!='SCHEDULED' GROUP BY t.id ORDER BY d.name, t.name"""


def rows_for(u):
    days = min(365, max(1, int(request.args.get("days", 30))))
    w, a = ("l.college_id=?", u["college_id"]) if u["role"] == "admin" else ("l.dept_id=?", u["dept_id"])
    out = q(SQL.format(w=w), (a, (dt.date.today() - dt.timedelta(days=days)).isoformat()))
    for r in out:
        done = r["held"] + r["missed"]
        r["rate"] = round(r["held"] * 100 / done) if done else None
        r["delay"] = None if r["delay"] is None else round(r["delay"])
        r["attendance"] = None if r["attendance"] is None else round(r["attendance"])
    return out

"""Weekly timetable: one slot generates the lectures for the coming weeks"""
import datetime as dt
from flask import Blueprint, request, session, jsonify, Response

from ..db import q, ex
from ..config import EARLY
from ..helpers import *

bp = Blueprint("timetable", __name__)


DAYS = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]


@bp.get("/api/timetable")
@need("teacher", "hod")
def slots(u):
    w, a = ("t.teacher_id=?", u["id"]) if u["role"] == "teacher" else ("t.dept_id=?", u["dept_id"])
    rows = q(f"SELECT t.*, c.name class_name, p.name teacher FROM timetable t JOIN classes c ON c.id=t.class_id "
             f"JOIN users p ON p.id=t.teacher_id WHERE {w} ORDER BY t.weekday, t.start_time", (a,))
    for r in rows: r["day"] = DAYS[r["weekday"]]
    return jsonify(rows)


@bp.post("/api/timetable")
@need("teacher")
def new_slot(u):
    d = body("class_id", "subject", "room", "weekday", "start", "end", "weeks")
    try:
        assert mins(d["end"]) > mins(d["start"]); wd = int(d["weekday"]); weeks = max(1, min(12, int(d["weeks"]))); assert 0 <= wd <= 6
    except Exception: raise ValueError("Check the day and times, and make sure the end time is after the start time")
    if not q("SELECT 1 FROM classes WHERE id=? AND dept_id=?", (d["class_id"], u["dept_id"]), one=True): raise ValueError("Unknown class")
    sid = ex("INSERT INTO timetable(college_id,dept_id,class_id,teacher_id,subject,room,weekday,start_time,end_time) VALUES(?,?,?,?,?,?,?,?,?)",
             (u["college_id"], u["dept_id"], d["class_id"], u["id"], d["subject"], d["room"], wd, d["start"], d["end"]))
    n, today = now(), dt.date.today(); made, skipped = 0, []
    for i in range(weeks * 7):
        day = today + dt.timedelta(days=i)
        if day.weekday() != wd or (day == today and n.hour * 60 + n.minute >= mins(d["end"])): continue
        date = day.isoformat()
        why = conflict(u["college_id"], u["id"], d["room"], date, d["start"], d["end"])
        if why: skipped.append(why); continue
        ex("INSERT INTO lectures(college_id,dept_id,class_id,teacher_id,subject,room,date,start_time,end_time,timetable_id) VALUES(?,?,?,?,?,?,?,?,?,?)",
           (u["college_id"], u["dept_id"], d["class_id"], u["id"], d["subject"], d["room"], date, d["start"], d["end"], sid)); made += 1
    log((u["college_id"], u["dept_id"]), u["id"], "TIMETABLE_CREATED", detail=f"{d['subject']} every {DAYS[wd]} {d['start']}-{d['end']}: {made} lectures scheduled")
    publish(u["college_id"]); return jsonify(made=made, skipped=len(skipped), reasons=skipped[:3])


@bp.post("/api/timetable/<int:sid>/delete")
@need("teacher")
def delete_slot(u, sid):
    s = q("SELECT * FROM timetable WHERE id=? AND teacher_id=?", (sid, u["id"]), one=True)
    if not s: raise ValueError("Timetable slot not found")

// App shell: routing, navigation, dialogs, menus, live refresh.
function tickEl() {
  document.querySelectorAll(".el").forEach(x => {
    const m = Math.max(0, Math.floor((Date.now() - new Date(x.dataset.since)) / 60000));
    x.textContent = m < 60 ? m + " min" : Math.floor(m / 60) + " h " + (m % 60) + " min";
  });
}

async function hydrate() {
  if (me?.role === "hod") STAFF = await api("/api/teachers").catch(() => STAFF);
  for (const el of document.querySelectorAll("[data-src]")) {
    if (el.contains(document.activeElement) && document.activeElement.matches("input,select")) continue;   // don't wipe what someone is typing
    try {
      const data = await api(el.dataset.src), keep = el.value;
      el.innerHTML = R[el.dataset.r](data);
      if (el.tagName === "SELECT") el.value = keep || el.options[0]?.value;
    } catch (x) {
      if (x.status === 401) return boot();
      el.innerHTML = `<div class="empty">${e(x.message)}</div>`;
    }
  }
  tickEl();
}

function shell() {
  const tabs = TABS[me.role];
  const org = me.college ? `<b>${e(me.college.name)}</b>${e(me.dept || me.college.code)}` : "<b>CampusLive</b>Platform administration";
  $("#root").innerHTML = `<div class="app"><aside class="rail">
    <div class="brand"><span class="dot on"></span>CampusLive</div><div class="org">${org}</div>
    <nav>${tabs.map((x, i) => `<button class="${i === tab ? "on" : ""}" data-tab="${i}">${x[0]}</button>`).join("")}</nav>
    <div class="chip"><span class="avatar">${initials(me.name)}</span>
      <button class="who" data-goto="Account" title="Your account"><b>${e(me.name)}</b><span>${ROLES[me.role]}</span></button>
      <button class="out" data-act="logout" title="Sign out" aria-label="Sign out">${ICON.out}</button></div>
  </aside><div class="workspace"><div class="topbar"><span class="conn" id="conn"><i class="dot"></i>Connecting</span><span class="clock" id="clk"></span></div>
  <main>${tabs[tab][1]()}</main></div></div>`;
  hydrate();
}

function connect() {
  es?.close(); es = new EventSource("/api/stream");
  const set = (on, t) => { const c = $("#conn"); if (c) { c.classList.toggle("on", on); c.lastChild.textContent = t; } };
  es.onopen = () => set(true, "Live updates connected");
  es.onerror = () => set(false, "Reconnecting");
  es.onmessage = () => hydrate();
}

function route() {
  if (me) return;
  const h = location.hash;
  h === "#signin" ? authView(false) : h === "#signup" ? authView(true) : landingView();
  scrollTo(0, 0);
}
window.addEventListener("hashchange", route);

async function boot() {
  try { me = (await api("/api/me")).user; } catch { me = null; }
  if (!me) { es?.close(); closeModal(); return route(); }
  history.replaceState(null, "", location.pathname); tab = 0; shell(); connect();
}

// ----- dialogs -----
function showModal(title, html, wide) {
  closeModal();
  document.body.insertAdjacentHTML("beforeend", `<div class="modal" id="modal" data-backdrop><div class="dialog ${wide ? "wide" : ""}" role="dialog" aria-modal="true" aria-label="${e(title)}">
    <div class="dhead"><h2>${e(title)}</h2><button class="x" data-close aria-label="Close">${ICON.x}</button></div><div class="dbody">${html}</div></div></div>`);
  $("#modal input:not([type=hidden]),#modal select")?.focus();
  hydrate();
}
const closeModal = () => $("#modal")?.remove();

async function openDetail(id) {
  try { const d = await api(`/api/lectures/${id}/detail`); showModal(d.lecture.subject, R.detail(d), true); }
  catch (x) { toast(x.message); }
}

// ----- three-dot menus -----
function closeMenus() {
  document.querySelectorAll(".menu:not([hidden])").forEach(m => { m.hidden = true; m.previousElementSibling?.setAttribute("aria-expanded", "false"); });
}
function toggleMenu(btn) {
  const m = btn.nextElementSibling, wasOpen = !m.hidden;
  closeMenus(); if (wasOpen) return;
  m.hidden = false; btn.setAttribute("aria-expanded", "true");
  const r = btn.getBoundingClientRect(), w = m.offsetWidth, h = m.offsetHeight;
  m.style.left = Math.max(8, Math.min(innerWidth - w - 8, r.right - w)) + "px";
  m.style.top = (r.bottom + 6 + h > innerHeight ? Math.max(8, r.top - h - 6) : r.bottom + 6) + "px";
}

document.addEventListener("submit", async ev => {
  const f = ev.target.closest("[data-post]"); if (!f) return;
  ev.preventDefault();
  const btn = f.querySelector("button:not([type=button])"); if (btn) btn.disabled = true;
  try {
    const r = await api(f.dataset.post, Object.fromEntries(new FormData(f)));
    if (["/api/login", "/api/register"].includes(f.dataset.post)) return boot();
    if (f.dataset.post === "/api/me/profile") { me = r.user; closeModal(); toast("Profile updated"); return shell(); }
    toast(r.code ? `College created. Its ID is ${r.code}`
      : r.made !== undefined ? `Weekly slot saved: ${r.made} lectures scheduled` + (r.skipped ? `, ${r.skipped} skipped for clashes. ${r.reasons[0]}` : "")

        <label>Class code from your teacher<input name="code" inputmode="numeric" maxlength="4" required></label>

    return sheet("Live for your class", d.live.length,
      d.live.length ? d.live.map(l => live(l) + checkin(l)).join("") : `<div class="empty">No lecture is live for your class right now.</div>`);
  }

  d.live.forEach(l => (by[l.dept] ??= []).push(l));

// Forms (shown inside pop-up dialogs)
const fieldsHtml = f => f.map(([n, l, ty = "text", x = "", opt]) => ty === "hidden" ? `<input type="hidden" name="${n}" value="${x}">`
  : `<label>${l}<input name="${n}" type="${ty}" ${opt ? "" : "required"} ${x}></label>`).join("");
const foot = (btn, cls = "pri") => `<div class="mfoot"><button type="button" class="btn" data-close>Cancel</button><button class="btn ${cls}">${btn}</button></div>`;
const formHtml = (url, f, btn, ok = "Saved", cls = "pri") => `<form class="mform" data-post="${url}" data-ok="${ok}">${fieldsHtml(f)}${foot(btn, cls)}</form>`;
const confirmHtml = (text, url, btn, ok, f = []) => `<p class="mtext">${text}</p>` + formHtml(url, f, btn, ok, "danger");

// Three-dot menus
const menu = items => `<div class="kebab"><button class="dots" data-menu aria-label="More actions" aria-haspopup="true" aria-expanded="false">${ICON.dots}</button><div class="menu" role="menu" hidden>${items.join("")}</div></div>`;
const mi = (label, attrs, cls = "") => `<button class="mi ${cls}" role="menuitem" ${attrs}>${label}</button>`;
const rowact = (primary, items) => `<div class="rowact">${primary}${items.length ? menu(items) : ""}</div>`;
